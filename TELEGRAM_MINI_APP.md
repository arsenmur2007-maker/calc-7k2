# Telegram Mini App — этап 1

Это адаптация существующего «Баланса месяца» для открытия через Telegram WebView. Сайт продолжает работать как обычная PWA.

## Запуск
1. Разместите содержимое папки на HTTPS-хостинге (например, GitHub Pages).
2. Создайте бота через @BotFather и задайте Mini App URL (публичный HTTPS-адрес `index.html`) через настройки бота.
3. Откройте Mini App через Telegram. Проверяйте на Android, iOS и Telegram Desktop.

## Что уже работает
- Определение Telegram Mini App через `Telegram.WebApp.initData` (не используется для проверки личности).
- `ready()`, `expand()`, учёт safe-area, кнопка «Назад» для закрытия редактора операций.
- Обычная браузерная PWA не меняет режим работы.

## Ограничения этапа 1
- Финансовые данные остаются в localStorage конкретного WebView/браузера. Данные не синхронизируются между Telegram и сайтом или разными устройствами.
- При очистке данных Telegram/WebView локальные записи могут быть потеряны. До начала работы сделайте JSON-резервную копию и храните её безопасно.
- Telegram `initData` должен проверяться на **сервере** по HMAC с токеном бота и сроком действия. Нельзя доверять `initDataUnsafe` или одному user.id из JavaScript.
- Не вставляйте токен бота в HTML/JS и не храните его в GitHub.
- Для этапа 2 нужны API, серверная база, миграция локальных записей, резервное копирование, контроль доступа и обработка конфликтов синхронизации.
- Не гарантируется offline-доступ внутри всех клиентов Telegram. Service Worker сохраняет обычную PWA.
