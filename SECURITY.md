# Безопасность «Баланс месяца»

Этот выпуск содержит локальные меры защиты: ограничение структуры и размера импортируемых резервных копий, белый список ключей финансовых настроек, ограничение размера/формата изображений обоев, проверку ссылок на HTTPS и кеширование только файлов оболочки PWA в service worker.

## Важно при публикации

- Публикуйте сайт исключительно через HTTPS (например, GitHub Pages с HTTPS).
- Не размещайте в репозитории реальные резервные копии, пароли, API-ключи и финансовые данные.
- При наличии собственного сервера настройте заголовки Content-Security-Policy (после проверки совместимости со встроенными скриптами), X-Content-Type-Options: nosniff, Referrer-Policy: strict-origin-when-cross-origin, а также HSTS для HTTPS-домена. Эти заголовки нельзя гарантированно установить только из статического HTML на GitHub Pages.
- Данные приложения в localStorage НЕ шифруются. Любой, кто получил доступ к профилю браузера, может их прочитать. Не используйте приложение как хранилище паролей или реквизитов карт.
- Резервные копии в буфере обмена остаются обычным JSON: храните их в защищённом месте.
- Это не аудит безопасности и не защита от вредоносных расширений или взломанного устройства.

## Проверка перед релизом

Проверьте на тестовой копии: создание/редактирование расходов, импорт корректной и повреждённой резервной копии, загрузку обоев PNG/JPEG/WebP, офлайн-запуск PWA, обновление service worker, обычный и полный сброс. Полный браузерный регрессионный тест в рамках этого обновления не выполнялся.
